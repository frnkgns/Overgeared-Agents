# OA Implementation Handoff

Inspects source/contracts/tests before changes. Uses GENTJIN project-conventions/architecture-review/etc as relevant. 
Implements smallest complete behavior (loading/error/empty/nullable, frontend/backend alignment). 
Returns affected paths, behavior changes, actual developer checks, limitations, recommended QA focus. 
No self-issue of QA/security verdict. No release/push/deploy authority; no unrelated refactors/deps.
